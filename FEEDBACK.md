# Feedback Log

Use this file during iterative development to capture user feedback and turn it into concrete follow-up work.

## How To Use

For each review cycle, record:

- Date
- User or stakeholder
- Scenario tested
- What worked
- What failed
- Suggested change
- Priority
- Status

## Entry Format

```md
## 2026-05-18

- User:
- Scenario:
- What worked:
- What failed:
- Suggested change:
- Priority:
- Status:
```

## Prioritization

- High: blocks use or causes incorrect behavior.
- Medium: slows users down or creates confusion.
- Low: polish or incremental improvement.
